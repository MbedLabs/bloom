Bloom is requirements management for teams that build hardware.

Requirements live in a hierarchy, carry attributes and revisions, and link to
each other and to the documents around them — so a change to a parent shows you
what it touches before you make it.

ReqIF import and export mean requirements can arrive from, and go back to,
whatever tool the rest of the supply chain uses. Issues can be synchronised with
GitHub or GitLab, so engineering work stays attached to the requirement that
asked for it.

Test results can be pulled in from Bud, EmbedLabs' test management tool, so a
requirement carries the evidence that verifies it rather than a link to it.
